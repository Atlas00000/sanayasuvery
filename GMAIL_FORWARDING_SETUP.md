# 📧 Gmail Auto-Forwarding Setup (2 Minutes)

## Why This is Needed

Resend's **free tier** only allows sending to the email you signed up with (emilicelestine@gmail.com).

**Solution:** Set up Gmail to auto-forward order emails to sanayascents@gmail.com

---

## Setup Steps

### Step 1: Open Gmail Settings (30 seconds)

1. Log into **emilicelestine@gmail.com**
2. Click the **gear icon** (⚙️) in the top right
3. Click **"See all settings"**
4. Go to the **"Forwarding and POP/IMAP"** tab

### Step 2: Add Forwarding Address (1 minute)

1. Click **"Add a forwarding address"**
2. Enter: `sanayascents@gmail.com`
3. Click **"Next"** → **"Proceed"** → **"OK"**
4. **Check sanayascents@gmail.com inbox**
5. You'll receive a **confirmation email** from Gmail
6. **Click the confirmation link**
7. Go back to emilicelestine@gmail.com settings
8. Select **"Forward a copy of incoming mail to sanayascents@gmail.com"**
9. Keep a copy: Select **"keep Gmail's copy in the Inbox"**
10. Click **"Save Changes"** at the bottom

### Step 3: Create Filter for Order Emails (Optional but Recommended)

This ensures ONLY order emails are forwarded:

1. In Gmail settings, go to **"Filters and Blocked Addresses"** tab
2. Click **"Create a new filter"**
3. In the **"Subject"** field, enter: `New Order - SAN`
4. Click **"Create filter"**
5. Check **"Forward it to"** and select `sanayascents@gmail.com`
6. Check **"Skip the Inbox (Archive it)"** if you don't want duplicates in personal inbox
7. Click **"Create filter"**

---

## Result

✅ **Every order email automatically goes to BOTH inboxes:**
- emilicelestine@gmail.com (primary - receives from Resend)
- sanayascents@gmail.com (auto-forwarded within seconds)

---

## Alternative: Verify a Domain (For Businesses)

If you own a domain (e.g., sanayascents.com), you can verify it with Resend:

1. Go to: https://resend.com/domains
2. Click **"Add Domain"**
3. Add DNS records (Resend provides them)
4. Wait for verification (usually 5-15 minutes)
5. Update code to use: `from: "Sanaya's Scents <orders@sanayascents.com>"`
6. Now you can send to unlimited addresses!

**Cost:** Domain verification is **free** on Resend, you just need to own the domain.

**Current Setup (After Gmail forwarding):**
```

    ↓
Gmail auto-forwards to sanayascents@gmail.com
    ↓
Both inboxes receive the order email
```

**Total time:** < 5 seconds for both emails to arrive!

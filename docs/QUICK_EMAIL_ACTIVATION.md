## Troubleshooting

**Still not receiving emails after activation?**

1. **Check spam/junk folders** in both inboxes
2. **Add noreply@formsubmit.co to contacts**
3. **Wait 1-2 minutes** (sometimes delayed)
4. **Whitelist FormSubmit:**
   - Gmail: Settings → Filters → Create filter for "formsubmit.co" → Never send to spam

**Can't find activation email?**
- Check spam folder
- Try placing another order
- Contact FormSubmit support if needed
